# Contributing

Issues are welcome: bugs, questions and ideas. Factory takes no outside pull requests until its owner says otherwise, through 0.9.x and 1.0 alike; only maintainers open them.

## Reporting a bug

[Open an issue](https://github.com/clockgrove/factory/issues/new) with:

- the Factory tag your workflow pins (`clockgrove/factory@vX.Y.Z`), the harness (Claude Code, Codex or Copilot) and the route (Actions, local mode or the cloud sandbox);
- what you expected and what happened, with a link to the Objective's issue or PR when it is public;
- the Blocked or Question comment's text, and `/factory:factory-doctor`'s lines when setup is involved.

Leave out tokens, keys and private code. Report a security problem privately instead (see [SECURITY.md](SECURITY.md)).

## Questions and ideas

Open an issue for these too. Say what you are trying to do; a real Objective that Factory handled badly is the most useful report there is.
