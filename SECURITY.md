# Security policy

Report a suspected vulnerability privately through GitHub's [private vulnerability reporting](https://github.com/clockgrove/pendulum/security/advisories/new) for this repository, never in a public issue or pull request. Include the version or commit, the affected path, and steps that reproduce it with synthetic data.

## Response targets

- **Acknowledgement:** within 3 business days of your report, on the advisory.
- **Initial assessment:** within 7 days: whether we can reproduce it, how severe we judge it, and what we plan to do.

## Supported versions

- **0.10.x:** the latest 0.10.x release gets security fixes; older tags, and every release before 0.10, do not.

Upgrade to the latest release to take a fix.
