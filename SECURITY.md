# Security policy

Report a suspected vulnerability privately through GitHub's [private vulnerability reporting](https://github.com/clockgrove/factory/security/advisories/new) for this repository, never in a public issue or pull request. Include the version or commit, the affected path, and steps that reproduce it with synthetic data.

## Supported versions

The latest 0.9.x release gets security fixes; older tags do not. Upgrade to the latest release to take a fix.
