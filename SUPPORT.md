# Support

Start with the [installation and use guide](README.md) and `factory help` for the installed CLI.

For a bug or documentation problem, search [existing issues](https://github.com/clockgrove/factory/issues), then [open a report](https://github.com/clockgrove/factory/issues/new/choose). Include:

- Factory version, operating system, and Node.js version.
- The command you ran, expected behavior, and observed behavior.
- Minimal reproduction steps, preferably in a disposable repository.
- Relevant redacted output and the point where the operation stopped.

Do not share credentials, private source, or agent transcripts containing sensitive data. A private repository is not a reason to publish its contents; describe the problem using public or synthetic inputs where possible.

For a feature request, explain the outcome you need and what the current workflow cannot do. Follow [SECURITY.md](SECURITY.md) for vulnerabilities and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns instead of opening a public issue.

Support is provided through the public issue tracker as maintainer time allows. There is no promised response time or commercial support channel.
