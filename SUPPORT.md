# Support

Read the [installation and use guide](README.md) and run `factory help` for the installed CLI. For a reproducible defect or documentation problem, [open an issue](https://github.com/clockgrove/factory/issues/new). Include the Factory version, Node.js version, relevant command, a minimal reproduction in a disposable target, and redacted output. Do not share credentials, private source, or agent transcripts containing sensitive data.

For a new capability, describe the target repository behavior and the outcome you need. For a security concern, follow [SECURITY.md](SECURITY.md) instead of opening a public issue. For community conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Factory is maintained in the open; support is provided through the public issue tracker as maintainer time allows. There is no promised response time or commercial support channel.
