# Factory archive-to-rebuild capability review

Status: operator-approved capability audit, September 22, 2026. The accepted pre-pilot trunk closure list is issues #19–#25 and #28, followed by the #26 pilot gate. T03, T11, and T26 were narrowed as noted below. Acceptance does not mean implementation is complete, and no row authorizes copying the archived implementation wholesale.

## Evidence and decision rule

The archived reference is `clockgrove/factory` at `994bbfcadb317aed2dfa932ec9d128e7d0d8c7a8`. I reviewed its `docs/DESIGN.md`, `docs/OPERATING-REFERENCE.md`, `docs/CONFORMANCE.md`, `docs/OBJECTIVE-ASSETS.md`, `docs/LARGE-FILES.md`, `docs/THREAT-MODEL.md`, `docs/OBJECTIVE-AUTHORITY.md`, and `docs/DELIVERY-PLAN.md`, then checked the named implementation paths below. The rebuild reference is `clockgrove/factory-rebuild` at `5aa5b28`, its public implementation plan and build status, its source-provenance ledger, current code, and the closed slice evidence. Archive paths below are relative to that pinned archived commit. Public issue links point to the implementation/acceptance owner; they are not evidence that the behavior is already complete.

`Proven` means a bounded installed or application-integration path exists in the public build status; it does **not** assert all edge cases or a published release. `Partial` means a narrower behavior exists but the recommended contract is not yet proven. `Absent` means no public rebuild surface for the capability. `Branch` and `Leave out` are scope decisions. Every retain/replace decision means **keep the product guarantee, not the archived protocol, limits, test file, or module topology**. The operator approved the decisions in this matrix; an implementing agent must still follow each linked issue's acceptance scope.

The archived paths are provenance, not required implementation instructions. An unrelated contributor can use this matrix, the public plan, and the linked issues without access to the archived repository.

## Approved local autonomy extension

[Program #243](https://github.com/clockgrove/factory/issues/243) supersedes the optional-host-integration deferral for explicitly authorized local user-service supervision and sequential batches. It also extends fixed graph activation with reviewed immutable revisions and explicit retry with bounded diagnosed repair under admitted operator policy. The capability issues own implementation and evidence; these changes are not enabled merely by this decision.

Retain one active Objective, one concrete coordinator, atomic local continuation state, exact evidence and target-owned gates. This decision does not restore archived code, distributed election, event journals, adaptive pressure, mixed execution modes or bursting. Installation does not silently start a service or authorize target work. Existing explicit runs keep their prior retry and authority semantics; compatible state reads or safe upgrade refusal replace silent active-run migration.

## New mismatch found during this review

`src/contracts.ts` still says `sourceAssets?: (string | SourceAssetBinding)[]` and calls string entries “Legacy path entries” readable in schema-version-1 snapshots. `src/compiler.ts` and `src/media.ts` still branch on that string form. That conflicts with the clean-start/no-backward-compatibility decision. The operator approved folding a **small trunk cleanup** into [#23](https://github.com/clockgrove/factory-rebuild/issues/23): use the one structured binding form in new graphs/state and remove the string adaptation, after checking current fixture/state consumers. Do not add migration machinery.

## Acceptance before further branch work

1. The operator accepted the retain/replace/defer/discard decisions and the resulting pre-pilot trunk closure list [#19–#25 and #28](https://github.com/clockgrove/factory-rebuild/issues). The archive is not automatically the specification.
2. For each retained partial/absent row, the linked issue or a separately approved issue states the smallest implementation and integration proof. Existing slice evidence is not relabeled as proof of a broader behavior.
3. Audit the merged diff and the public `BUILD-STATUS.md` against this matrix before calling the trunk shippable. The public repo, not this conversation or a private local artifact, must contain the final decision record and contributor instructions.
4. Publish/install the exact public artifact and complete the private Clockgrove pilot through that public surface. Only then start the named cloud/sandbox branches or repository cutover.
