# Integration coverage

Which case checks each Factory behaviour that needs real GitHub or real providers. Run `npm run integration -- --dry-run` for every case and whether it runs on a given build.

**Preconditions,** in brackets: `approval` needs `--allow-repo-changes`, `reset` needs a build with `factory reset`, and `bound` needs a build that binds answers to questions (`--question`). Without one, the case records UNREACHABLE with the reason, never FAIL.
