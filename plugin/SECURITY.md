# Security policy

This plugin is part of Clockgrove Pendulum, and the repository's [security policy](https://github.com/clockgrove/pendulum/blob/main/SECURITY.md) covers it: how to report a suspected vulnerability privately, the response targets, and the supported versions. Report through GitHub's [private vulnerability reporting](https://github.com/clockgrove/pendulum/security/advisories/new), never in a public issue or pull request.
