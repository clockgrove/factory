# pendulum report: the JSON

`pendulum report --json` prints one object, schema `pendulum-report/1`. Dollars are US dollars rounded to a millionth, each one vendor-reported, or API-reported tokens at the published rate, or left unknown.

A **cost** is `{usd: {api, subscription, credits, unknown, sandbox}, unknownRuns, unknownWhy}`: each kind's known dollars (0 for none), never summed across kinds; the runs whose cost was not reported, and their reason codes. **Tokens** are `{input, output, cached, written}` where a record reports them (input includes cache reads and writes), else null.

| Field | Holds |
| --- | --- |
| `schema`, `repository`, `generatedAt`, `pendulum` | The schema version, `OWNER/NAME`, when it was made, the Pendulum release that made it |
| `scope` | `since`, `until`, `defaultPeriod` (true: the last 30 days, nothing named), `issues`, `label`, `parent`, `compare` (the two arms' labels, or null), `by` |
| `words` | The label for each cost kind |
| `totals` | `objectives`, `stages`, `passes`, `cost`, `tokens`; `asked` and `churn` (the Objectives' rows summed); `perMerged`: over the Objectives merged in the period, each whole: `n`, `usd` per kind, `wallMinutes`, `reviewRounds`, `fixPasses` (each `{median, p25, p75, n, leftOut}`), `leftOut` (`issue`, `why`: `records-unread`, `comments-stopped`, `unknown-runs`, `no-passes`, `no-clock`) |
| `unknown` | `runs`; `reasons` (`code`, `stages` naming it, `runs` or null when a stage gives it with another reason, `text`); `items` (`issue`, `stage`, `runs`, `why`) |
| `breakdowns` | `stage` (`work`, `rebase`, `review`, `decisions`), `pass` (from per-pass ledgers, and a stage's spend-line dollars by pass where it has no ledger, `spendLineStages`; `passes`, `modelMinutes`; a last row with `key` null: the dollars no pass names, never negative), `model`, `harness`, `version`, `route` (`actions`, `local`, `sandbox` as each stage's spend line records it, `decisions`; null: not recorded), `day` (the UTC date a stage started, oldest first), and `account` only with `--by account`. Rows: `key` (null: not recorded), `stages`, `cost`, `tokens`. Each covers the totals |
| `objectives` | Per Objective: `issue`, `title`, `url`, `outcome` (`merged`, `blocked`, `question`, `closed-unmerged`, `open`, or null when not read), `stages` (`work`, `rebase`, `review`), `passes` (`total`, `answer`, `fix`, or null), `cost`, `tokens`, `modelMinutes`, `usdPerModelMinute` (per billing kind), `unpricedPasses`, `findings` (or null); `asked` (`what`: `work`, `review`, `answer`, `fix`, `decision`, `sandbox`) and `churn` (`row`: `rebase-conflict`, `rebase-clean`, `catch-up`, `judge`, `block`; `stages`), each with `usd` per kind and `unknownRuns`, the finish card's breakdown; `started`, `merged`, `wallMinutes` (null with `clockWhy`: `not-merged`, `outcome-unread`, `no-card`, `no-label`); `route` (`mixed` for more than one; null: not recorded), `blocks` (Blocked notices in the period), `running` |
| `findings` | Review findings and how each ended (`fixed-test`, `fixed-verdict`, `answered`, `not-fixed`, `not-checkable`, `open`, in `outcomes`): `totals` and each Objective's `findings` (`findings`, `outcomes`, `reviewStages`, `cost` of those review stages, `unnamed`); `byReviewer` (`key` the reviewer model or an outside reviewer's login, `outside`, `findings`, `outcomes`, `reviewStages`, `cost`; null for an outside reviewer); `byStage` (`issue`, `stage`, `model`, `findings` its reviewer raised, `outcomes`, `cost`) |
| `hotSpots` | `reviewLoops`, `answerAndFixPasses`, `cacheWriteShare`, `costPerModelMinute`, `blockedOrUnmergedSpend`, `blockedStages` (stages whose spend line says they ended Blocked: `stages`, `keys`, `cost`; `unrecorded`: Objectives with a stage that does not say): each `{rankBy, items}`, largest first |
| `comparison` | Null without `--compare`. Else `inBoth` and two `arms`: `label`, `experiment`, `n`, `outcomes`, `merged`, `usdPerMerged` (per cost kind), `modelMinutes`, `wallMinutes`, `reviewRounds`, `fixPasses` (each `{median, p25, p75, n, leftOut}` over merged Objectives), `findings` (counts over the arm's Objectives with a findings record), `unknown` (`runs`, `objectives`, `reasons`), `untrusted`, `unverifiable`, `unchecked`, `objectives` (per-Objective rows). With it, `totals` and the rest cover both arms together |
| `rates` | Null without `--rates MODEL[,MODEL...]`. Else `words`, `candidates`, `basis`, `tables` (`vendor`, `file`, `date`), `items` (`model`, `rateOf`, `candidate`, `candidateRateOf`, `vendor`, `mix` and `long`: the recorded tokens and their long-context share as uncached, cached, written and output, `ratio`: the candidate's published rates over the model's on that mix, no unit) and `skipped` (`model`, `candidate`, `why`, `text`). One vendor's models only; never dollars |
| `source` | `complete`, `stoppedAt`, `maxCalls`, `calls` (`planned`, `plannedAtLeast`, `made`, `byKind`), `trusted` (`logins`, `app`, `appFrom`: `flag`, `variable`, `variable-gh`, `local-copy`, `env`, or with no id `unset`, `forbidden`; `appWhy`: `unset` or `forbidden` when the variable gave no id), `read`, `missing` (`code`, `count` in the code's own unit, `counts`: `{objectives, stages}`, each null where the code concerns neither, `issues`, `text`) |

Who counts: a marker counts only from Pendulum's own login, a login `--self` names that can push, or its App (`--app`, else the repository variable `PENDULUM_APP_ID`). A stage comment by another login that can push, or through another App, is a run of unknown cost (`unattributed`); anyone else's counts nothing. An arm's label, or an experiment `--label`, counts for an issue only when its last applier can push. The full contract: [The cost report](https://github.com/clockgrove/pendulum/blob/v0.10.0/docs/REPORT.md#schema).
