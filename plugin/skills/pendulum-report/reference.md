# pendulum report: the JSON

`pendulum report --json` prints one object, schema `pendulum-report/2`. Dollars are US dollars rounded to a millionth, each one vendor-reported, or API-reported tokens at the published rate, or left unknown.

A **cost** is `{usd: {api, subscription, credits, unknown, sandbox}, unknownRuns, unknownDecisionCalls, unknownWhy}`: each kind's known dollars (0 for none), never summed across kinds; the runs whose cost was not reported (harness passes, stages with no record, decision calls), the decision calls among them, and their reason codes (`running`: in flight while the Objective runs). A **pass** is a harness pass; a decision record is none (`decisionRecords`). **Model minutes** are harness passes' start to end. **Tokens** are `{input, output, cached, written}` where a record reports them (input includes cache reads and writes), else null.

| Field | Holds |
| --- | --- |
| `schema`, `repository`, `generatedAt`, `pendulum` | The schema version, `OWNER/NAME`, when it was made, the Pendulum release that made it |
| `scope` | `since`, `until`, `defaultPeriod` (true: the last 30 days, nothing named), `issues`, `label`, `parent`, `compare` (the two arms' labels, or null), `by` |
| `words` | The label for each cost kind |
| `totals` | `objectives`, `stages`, `passes`, `decisionRecords`, `cost`, `tokens` |
| `unknown` | `runs`; `decisionCalls`; `reasons` (`code`, `stages` naming it, `runs` or null when a stage gives it with another reason, `text`); `items` (`issue`, `stage`, `runs`, `decisionCalls`, `why`) |
| `breakdowns` | `stage` (`work`, `rebase`, `review`, `decisions`), `pass` (from per-pass ledgers; `passes`, `decisionRecords`, `modelMinutes`), `model` (with `usdPerModelMinute`), `harness`, `version`, and `account` only with `--by account`. Rows: `key` (null: not recorded), `stages`, `cost`, `tokens` |
| `objectives` | Per Objective: `issue`, `title`, `url`, `outcome` (`merged`, `blocked`, `question`, `closed-unmerged`, `open`, or null when not read), `stages` (`work`, `rebase`, `review`), `reviewRounds` (review stages that ran a pass), `passes` (`total`, `answer`, `fix`, or null), `decisionRecords`, `cost`, `tokens`, `modelMinutes` (every harness pass's, or null when one has no times), `usdPerModelMinute` (per billing kind: `usd`, `pricedMinutes`, `pricedPasses`, `usdPerModelMinute`), `unpricedPasses`, `findings` (or null) |
| `findings` | Review findings and how each ended (`fixed-test`, `fixed-verdict`, `answered`, `not-fixed`, `not-checkable`, `open`, in `outcomes`): `totals` and each Objective's `findings` (`findings`, `outcomes`, `reviewStages`, `cost` of those review stages, `unnamed`); `byReviewer` (`key` the reviewer model or an outside reviewer's login, `outside`, `findings`, `outcomes`, `reviewStages`, `cost`; null for an outside reviewer); `byStage` (`issue`, `stage`, `model`, `findings` its reviewer raised, `outcomes`, `cost`) |
| `hotSpots` | `reviewLoops` (review rounds and `reviewerPasses` per Objective), `answerAndFixPasses`, `cacheWriteShare`, `costPerModelMinute` (per model), `blockedOrUnmergedSpend`: each `{rankBy, items}`, largest first |
| `comparison` | Null without `--compare`. Else `inBoth` and two `arms`: `label`, `experiment`, `n`, `outcomes`, `merged`, `usdPerMerged` (per cost kind), `modelMinutes`, `wallMinutes`, `reviewRounds`, `fixPasses` (each `{median, p25, p75, n, leftOut}` over merged Objectives), `findings` (counts over the arm's Objectives with a findings record), `unknown` (`runs`, `objectives`, `reasons`), `untrusted`, `unverifiable`, `unchecked`, `objectives` (per-Objective rows). With it, `totals` and the rest cover both arms together |
| `rates` | Null without `--rates MODEL[,MODEL...]`. Else `words`, `usable` (false: no ratio could be weighed), `candidates`, `basis`, `tables` (`vendor`, `file`, `date`), `items` (`model`, `rateOf`, `candidate`, `candidateRateOf`, `vendor`, `mix` and `long`: the recorded tokens and their long-context share as uncached, cached, written and output, `ratio`: the candidate's published rates over the model's on that mix, no unit) and `skipped` (`model`, `candidate`, `why`, `text`). One vendor's models only; never dollars |
| `source` | `complete`, `stoppedAt`, `maxCalls`, `calls` (`planned`, `plannedAtLeast`, `made`, `byKind`), `trusted` (`logins`, `app`, `appFrom`: `flag`, `variable`, `variable-gh`, `local-copy`, `env`, or with no id `unset`, `forbidden`; `appWhy`: `unset` or `forbidden` when the variable gave no id), `read`, `missing` (`code`, `count` in the code's own unit, `counts`: `{objectives, stages}`, each null where the code concerns neither, `issues`, `text`) |

Who counts: a marker counts only from Pendulum's own login, a login `--self` names that can push, or its App (`--app`, else the repository variable `PENDULUM_APP_ID`). A stage comment by another login that can push, or through another App, is a run of unknown cost (`unattributed`); anyone else's counts nothing. An arm's label, or an experiment `--label`, counts for an issue only when its last applier can push. The full contract: [The cost report](https://github.com/clockgrove/pendulum/blob/v0.10.0/docs/REPORT.md#schema).
